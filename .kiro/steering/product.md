# Product Overview

## Totogi Customer Toolkit

An enterprise-ready Management toolkit that enables customers to deploy modular business capabilities into their own AWS accounts. The solution provides a guided, license-controlled deployment experience with comprehensive operational tooling.

## Core Value Proposition

Self-contained management platform that allows enterprise customers to:
- Deploy modular business capabilities to their AWS/Azure/GCP/Onprem infrastructure
- Choose between SaaS-hosted or Customer-managed deployment models
- Manage multiple isolated environments (dev, staging, production)
- Monitor and maintain deployed capabilities with built-in operations tools
- Receive continuous delivery of new capabilities and patches

## Key Features

### Progressive Web Application (PWA)
- Browser-based access with modern web standards
- Installable as web app on desktop and mobile
- Offline viewing capability for documentation
- Push notifications for deployment updates

### Electron Desktop Application
- Native desktop experience derived from PWA
- Enhanced file system access for logs and configurations
- System tray integration for background monitoring
- Auto-update functionality for seamless upgrades

### Authentication & Authorization
- Multi-factor authentication (TOTP, SMS, email)
- License key validation tied to organization/tenant
- Role-Based Access Control (Administrator, Operator, Viewer)
- SSO integration (SAML 2.0, OAuth 2.0, OpenID Connect)

### Deployment Management
- Guided deployment wizard for capability installation
- Multi-environment support (dev, staging, prod)
- AWS CloudFormation orchestration
- Real-time deployment progress tracking

### Operations & Monitoring
- Health checks and endpoint status
- CloudWatch integration for logs and metrics
- Downloadable or centralized log retrieval
- Notifications and alerts for deployment issues

### Lifecycle Management
- Version tracking per capability
- Patch application to individual capabilities
- Rollback to previous versions
- Continuous capability delivery via GitHub/S3
